#### 📇 플래시카드 — 시험 문제를 한 장씩 넘겨 보며 외우는 사이트

과목 평가를 위한 사이트를 만들어 봤어요.

**👉 https://flash-card-alpha-eight.vercel.app**

| 환경      | 이렇게 누르세요                                                              |
| --------- | ---------------------------------------------------------------------------- |
| 🖥 PC     | `→` 다음 카드 · `←` 이전 카드 · "펼치기" 버튼 클릭                           |
| 📱 모바일 | 화면을 **왼쪽으로 쓸면 다음**, **오른쪽으로 쓸면 이전** · "펼치기" 버튼 터치 |

##### 기능

- **펼치기**: 누르면 정답과 해설이 나오고, 객관식은 정답 보기가 초록색으로 표시됩니다
- **필터**: 위쪽 버튼으로 전체 / 객관식 / 단답형 / 주관식만 골라 볼 수 있습니다
- 열 때마다 **문제 순서가 무작위**로 섞이고, 마지막 카드에서 더 넘기면 다시 섞어 처음부터 시작합니다

##### 들어 있는 문제

- 데이터 엔지니어링 **171문제** (객관식 84 · 단답형 44 · 주관식 43)
- 주제: Docker, Docker Compose, Kafka 등
